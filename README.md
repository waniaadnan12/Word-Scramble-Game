# 🔤 Word Scramble Game

A simple **Word Scramble Game** made with Python 🐍.

The program randomly scrambles words and gives the player up to **3 attempts** to guess the correct word.

![Word Scramble](https://wordscramble.eu/img/scramble-puzzle.webp)

## 🎮 How It Works

1. The program has a list of words.
2. A word is randomly selected.
3. The letters of the word are scrambled.
4. You have **3 attempts** to guess the original word.
5. If you guess correctly, you win!
6. If you use all 3 attempts, the game shows the correct answer.

## 🛠️ Built With

- 🐍 Python
- `random` module
